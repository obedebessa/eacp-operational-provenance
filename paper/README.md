# Accompanying manuscripts

This directory contains two separately labeled manuscripts:

- `EACP_preprint.pdf` is the searchable PDF of the released version 1.2
  preprint / technical report. Its article/preprint DOI is
  <https://doi.org/10.5281/zenodo.22017662>.
- `EACP_preprint_v1.3_candidate.pdf` is the searchable reviewer-candidate
  manuscript dated 2026-09-02. It is not an archival release, has no v1.3 DOI,
  and must not be cited with the v1.2 DOI as though that DOI covered its new
  experiments or claims.

Neither manuscript has undergone peer review.
