# Accompanying manuscripts

This directory contains two separately labeled preprint versions:

- `EACP_preprint.pdf` is the searchable PDF of the released version 1.2
  preprint / technical report. Its article/preprint DOI is
  <https://doi.org/10.5281/zenodo.22017662>.
- `Cross_Plane_Operational_Provenance_Preprint_v1.3.0.pdf` is the searchable
  version 1.3.0 preprint dated 2026-09-03. Its version-specific DOI is
  <https://doi.org/10.5281/zenodo.22283868>, and its preprint Concept DOI is
  <https://doi.org/10.5281/zenodo.22017661>.

Neither manuscript has undergone peer review.
