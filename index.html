Cross-Plane Operational Provenance in Cloud-Native Systems: A Reproducible Evaluation of EACP

Abstract

Cloud-native operations distribute audit-relevant evidence across delivery, identity, orchestration, policy, telemetry, incident, and recovery systems. This paper presents an evidence-aware control plane (EACP), an asynchronous pattern that normalizes minimal source metadata into an append-only, service-level index while retaining authoritative artifacts in native systems and remaining outside application request paths by default. We evaluate a Python and SQLite reference implementation against six separately indexed source tables using deterministic workloads of 10,000, 50,000, and 100,000 events, ten seeded trials per size, and 600 reconstruction queries per trial. At 100,000 events, median p95 service-state query latency was 0.691 ms versus 1.141 ms for the fragmented baseline (1.65×), and correlation reconstruction was 0.022 ms versus 0.045 ms (2.05×). All sampled results and complete normalized projections matched. The EACP database, however, was 1.81× the fragmented-baseline size, or approximately 81% larger; retaining both produced a combined footprint near 2.81× the source-only baseline. A second laboratory evaluation used a real single-node Kubernetes v1.36.1 kind cluster. EACP persisted all 374 sanitized API-server audit events, including three HTTP 403 authorization denials, and append-only triggers rejected updates and deletions. Replays through an OpenTelemetry Collector reference pipeline retained 374/374 events in every run; an external validator matched 4,862/4,862 projected values. These results establish local feasibility, reproducibility, Kubernetes integration, and corpus preservation—not production effectiveness, semantic accuracy under missing or ambiguous correlation identifiers, or distributed-system scalability.
